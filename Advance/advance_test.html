高一自然科學科能力測驗

測驗限時 40 分鐘。客觀題（60分，系統即時核分），主觀解答題（40分，拍照上傳）。

第一部分：客觀科學素養題 (共 60 分)

1. 【物理】質點初速 $v_0 = 0\,\text{m/s}$，加速度 $a = 2\,\text{m/s}^2$，位移 $\Delta x = 16\,\text{m}$。依公式 $v^2 = v_0^2 + 2a\Delta x$，末速度 $v$ 為何？(10分)
2. 【化學】平衡反應 $\text{N}_2(g) + 3\text{H}_2(g) \rightleftharpoons 2\text{NH}_3(g)$，平衡常數 $K_c$ 正確式為何？(10分)
3. 【數學】一元二次方程式 $ax^2 + bx + c = 0$ ($a \neq 0, \Delta = b^2 - 4ac \ge 0$)，公式解 $x$ 為何？(10分)
4. 【生物】光合作用總式：$6\text{CO}_2 + 6\text{H}_2\text{O} \to \text{C}_6\text{H}_{12}\text{O}_6 + 6\text{O}_2$。下列敘述何者正確？(10分)
5. 【是非題】在孤立系統中，總能量保持恆定，能量只能轉換形式不能憑空生滅（能量守恆定律）。(10分)
6. 【是非題】在 $25^\circ\text{C}$ 水溶液中，$\text{pH} = -\log_{10}[\text{H}^+]$。若 $[\text{H}^+] = 10^{-3}\,\text{M}$，則 $\text{pH} = 3$，呈酸性。(10分)
